## 用户确认的设计决策（2026-07-07）

1. 重点功能是**古典排盘、Horary、行运扫描（Transit Scan）**三个工作流。
2. **吠陀模式只保证不回归**：沿用现有视图，不做新视图（分盘缩略图网格、Dasa 时间条等一律不做）。
3. 配色：**保留现有羊皮纸 "Celestial Almanac" 作为浅色主题**；新增**深空夜色 Dark Mode**，用户可在程序设置里选 跟随系统 / 浅色 / 深色。
4. 布局重构要点：
   - 本命档案信息升到顶部常驻（档案胶囊 + 快速切换）；
   - 流派切换（古典/现代/吠陀）从左侧导航栏移到顶栏；
   - 主"排盘/计算"按钮移到顶栏；
   - 中间参数栏变成"参数抽屉"：计算成功后自动收起，收起态是带竖排"参数"字样的窄条；
   - 结果区后续把横向 tab 换成垂直目录（古典 / Horary 优先）；
   - 扫描结果增加时间轴视图（表格保留，可切换）；
   - AI 分析后续改为全局右侧滑出面板。

## 全局强约束（每期任务书都适用）

0. 全部施工在分支 `codex/frontend-redesign-2026-07` 上进行（从最新 `main` 创建），每期一笔 commit，不 push、不打包，等验收。
1. **只改 Swift 界面层**（`Sources/TransitStudio/*.swift`）。Python 后端（`Sources/TransitStudio/Resources/backend/`）、星历文件、`Examples/`、`python_tests/` 一律禁改（任务书明确允许的除外）。
2. **禁止顺手重构**：不重命名、不挪文件、不改无关格式。diff 越小越好。
3. 每期完成后跑门禁：`bash check_vibe_changes.sh` 必须全绿。
4. 每期更新 `CHANGELOG.md` 顶部条目和 `PLANS.md` 状态，并按上表在 `package_app.sh` 里提升 `APP_VERSION` / `BUILD_VERSION`（只改这两行，不要运行打包脚本，打包由验收轮决定）。
5. 若任务书之外的文件被迫改动，**停下来向用户报告**，不要擅自扩大范围。
6. 遵守 `AGENTS.md` 的既有契约，特别是：
   - Result-Pane Tab Contract（tab id 必须有对应 case，标题走 `resultTabTitle()`）；
   - AI Streaming Contract（禁止逐 token 写入 per-mode storage、禁止在 body 里解析 markdown）。
7. 中文 UI 文案风格对齐现有界面（如"程序设置""窗口扫描"）。
